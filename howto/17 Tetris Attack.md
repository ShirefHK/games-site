# Tetris Attack

## Goal
Puzzle mode: clear all blocks with a limited number of moves.

## Controls
| Input | Action |
| --- | --- |
| Click | Move a block |
| R | Restart |
| N / P | Next / previous puzzle |

## How to play
1. Look at the "Moves left" counter; the limit equals the minimum possible number.
2. Move blocks so groups line up and disappear.
3. Falling blocks can chain into extra matches.

## Tips
- Plan the whole puzzle before the first move.
