# NetWalk (Pipe Puzzle)

## Goal
Rotate pipes until every computer is connected to the server.

## Controls
| Input | Action |
| --- | --- |
| Click | Rotate a pipe |
| R | New puzzle |

## How to play
1. Find the server and the computers.
2. Click pipes to rotate them so cables link up.
3. All computers must be powered at once.

## Tips
- Start with the corners and the ends of the grid; they have only a few options.
