# 2048

## Goal
Slide the tiles and merge equal numbers to reach 2048.

## Controls
| Input | Action |
| --- | --- |
| Arrows / WASD | Slide all tiles |
| Swipe | Slide (touch) |
| R | Restart |

## How to play
1. All tiles slide the same way.
2. Two tiles with the same number merge into one.
3. Reach 2048, then keep going if you want.

## Tips
- Keep your biggest tile in a corner.
