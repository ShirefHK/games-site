# Quadwords

## Goal
Solve four words at once; every guess is played on all four boards.

## Controls
| Input | Action |
| --- | --- |
| Letters | Type |
| Enter | Submit |
| Backspace | Delete |
| Esc | New game |

## How to play
1. Type a 5-letter word and press Enter.
2. The guess is applied to all four boards.
3. You have 9 guesses to solve all four.

## Tips
- Use the first guesses to find letters.
