# Gridlock

## Goal
Slide the cars out of the way to free the red car.

## Controls
| Input | Action |
| --- | --- |
| Drag | Move a car along its lane |
| N | New jam |
| R | Restart |
| H | Hint |

## How to play
1. Drag cars forward or back.
2. Create a path to the exit on the right.
3. Try to beat the best possible move count.

## Tips
- Use H for a hint.
