# Bookworm

## Goal
Link adjacent letter tiles into words of 3 or more letters.

## Controls
| Input | Action |
| --- | --- |
| Click tiles | Spell a word |
| Enter | Submit word |
| Backspace | Undo last letter |
| Esc | Clear |
| R | New game |

## How to play
1. Click neighbouring tiles to spell a word.
2. Press Enter (or click the last tile again) to submit.
3. Use fire tiles in a word before they burn down.

## Tips
- Longer words score better.
