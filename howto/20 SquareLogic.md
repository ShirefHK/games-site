# SquareLogic

## Goal
A number-grid puzzle with sum cages. Fill each row and column with 1–N exactly once.

## Controls
| Input | Action |
| --- | --- |
| Click | Select a cell |
| 1–N | Fill the cell |
| 0 / Backspace | Clear |
| Space | Toggle pencil notes |
| [ ] | Change grid size |
| R | New puzzle |

## How to play
1. Click a cell and type a number.
2. The number in a cage corner is the sum of that cage.
3. Each row and column uses every number exactly once.

## Tips
- Fill small cages first.
