# Pitfall

## Goal
3D Tetris: drop blocks into a pit and fill whole layers.

## Controls
| Input | Action |
| --- | --- |
| Arrows | Move |
| Z / X / C | Rotate around X / Y / Z axis |
| Space | Drop to the bottom |
| R | Restart |

## How to play
1. Move the piece above the pit.
2. Rotate it on any of the three axes.
3. Complete flat layers to clear them.

## Tips
- Watch the depth bar; overflowing the pit ends the game.
