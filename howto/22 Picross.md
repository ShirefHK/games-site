# Picross

## Goal
Use the number clues to reveal the hidden picture.

## Controls
| Input | Action |
| --- | --- |
| Left click / drag | Fill |
| Right click / drag, or Shift | Mark X |
| N / P | Next / previous puzzle |
| R | Restart |

## How to play
1. Each number tells how many filled squares in a row or column are next to each other.
2. Fill the squares you are sure about and mark X where there is nothing.
3. Wrong fills cost time.

## Tips
- Start with long runs; they leave little room.
