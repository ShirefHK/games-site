# Minesweeper

## Goal
Reveal every safe square without clicking a mine.

## Controls
| Input | Action |
| --- | --- |
| Left click | Reveal a square |
| Right click | Place / remove a flag |
| R | New game |

## How to play
1. A number shows how many mines touch that square.
2. Use the numbers to deduce where the mines are and flag them.
3. Reveal every square that is not a mine to win.

## Tips
- Start in a corner or on a 0 square to open large areas.
- Flags are only a note to yourself; you do not have to flag everything.
