# Kendoku

## Goal
Fill the grid with 1–N and satisfy the arithmetic cages.

## Controls
| Input | Action |
| --- | --- |
| Click | Select a cell |
| Digits | Enter number |
| Arrows | Move |
| Backspace | Clear |
| R | New puzzle |

## How to play
1. Each row and column has every digit once.
2. Cage targets must match the given operation.
3. Fill the grid.

## Tips
- Start with single-cell cages.
