# Pfeile

## Goal
Arrow puzzle. Use the arrow clues to fill the grid.

## Controls
| Input | Action |
| --- | --- |
| Click | Select |
| Arrows | Move |
| Digits | Enter |
| R | New puzzle |

## How to play
1. Click a cell.
2. Use the arrows as hints.
3. Fill the grid.

## Tips
- Start with the corners.
