# Sokoban

## Goal
Push every crate onto a target square.

## Controls
| Input | Action |
| --- | --- |
| Arrows / WASD | Move and push |
| Z | Undo |
| R | Restart |
| N / P | Next / previous level |

## How to play
1. Walk into a crate to push it one square.
2. You can only push, never pull.
3. Cover every target to finish.

## Tips
- Do not push a crate into a corner.
- Undo with Z.
