# Quintext

## Goal
Swap letters until every row is a valid 5-letter word.

## Controls
| Input | Action |
| --- | --- |
| Click, click | Swap two letters |
| H | Hint |
| R | New puzzle |

## How to play
1. Click two letters to swap them.
2. Each row must be a valid word.
3. The counter shows how many rows are words.

## Tips
- Use H when stuck.
