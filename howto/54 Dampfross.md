# Dampfross

## Goal
Lay railway track from A to B.

## Controls
| Input | Action |
| --- | --- |
| Click / drag | Add / remove rail |
| R | New puzzle |

## How to play
1. Row and column numbers show how many rail cells.
2. The track is one line from A to B.
3. It never touches itself.

## Tips
- Look for rows with all cells.
