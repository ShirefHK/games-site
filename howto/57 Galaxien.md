# Galaxien

## Goal
Divide the grid into galaxies. Each is symmetric around its dot.

## Controls
| Input | Action |
| --- | --- |
| Click dot | Select galaxy |
| Click cells | Add / remove cells |
| R | New puzzle |

## How to play
1. Click a dot.
2. Click cells to add; the symmetric partner is added too.
3. Every cell must belong to a galaxy.

## Tips
- Cells near a dot are easy to assign first.
