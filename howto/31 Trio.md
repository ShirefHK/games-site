# Trio

## Goal
Find sets of three cards: each feature must be all the same or all different.

## Controls
| Input | Action |
| --- | --- |
| Click | Pick three cards |
| H | Hint |
| R | New game |

## How to play
1. Pick three cards.
2. For every feature, the three must all match or all differ.
3. Find every set.

## Tips
- Say the rule aloud: two the same + one different = not a set.
