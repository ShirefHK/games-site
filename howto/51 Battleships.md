# Battleships

## Goal
Find the hidden fleet using the row and column numbers.

## Controls
| Input | Action |
| --- | --- |
| Click | Unknown → ship → water |
| Right click | Water |
| R | New puzzle |

## How to play
1. The numbers say how many ship cells are in that row or column.
2. Ships are straight and never touch, not even diagonally.
3. Mark water around found ships.

## Tips
- Look for rows with the number 0 first.
