# Loopy

## Goal
Draw one closed loop. Numbers show how many of a cell's edges are used.

## Controls
| Input | Action |
| --- | --- |
| Click an edge | Draw / erase |
| Right click | Mark "no line" |
| R | New puzzle |

## How to play
1. Click edges to draw the line.
2. Each number says how many sides of that cell are used.
3. The loop must close up.

## Tips
- Mark impossible edges with a right click.
