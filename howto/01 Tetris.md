# Tetris

## Goal
Stack the falling blocks into complete horizontal rows. Full rows vanish; the game ends when the stack reaches the top.

## Controls
| Input | Action |
| --- | --- |
| ← → | Move the piece |
| ↑ | Rotate |
| ↓ | Soft drop (fall faster) |
| R | Restart |

## How to play
1. Guide each piece left or right to where it fits.
2. Rotate it so it slots in without leaving holes.
3. Clear several rows with one piece for a bigger score: 100 / 300 / 500 / 800 for 1–4 rows.

## Tips
- Keep the stack flat and low.
- Leave one column open for long pieces to clear four rows at once.
