# SpaceChem

## Goal
Program atom-moving "Waldo" robots to build molecules.

## Controls
| Input | Action |
| --- | --- |
| 1–6 / click palette | Pick a tool |
| Click | Place on a cell |
| Right click | Erase |
| Space | Run / stop |
| S | Single step |
| H | Show a solution |
| N / P | Next / previous level |

## How to play
1. Pick a tool and lay out arrows and actions on the grid.
2. Press Space to run and watch the Waldo.
3. Do not let it hit the reactor wall.

## Tips
- Step through with S to find mistakes.
- H shows a solution if stuck.
