# Gridwords

## Goal
Guess the 5-letter word in 6 tries.

## Controls
| Input | Action |
| --- | --- |
| Letters | Type |
| Enter | Submit |
| Backspace | Delete |
| Esc | New practice word |

## How to play
1. Type a 5-letter word and press Enter.
2. Green: right place. Yellow: wrong place. Grey: not in the word.
3. One daily word, same for everyone.

## Tips
- Start with words that have common vowels.
