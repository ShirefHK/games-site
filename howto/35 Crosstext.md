# Crosstext

## Goal
Word search: find the hidden words from the list.

## Controls
| Input | Action |
| --- | --- |
| Drag | Select letters in a line |
| R | New puzzle |

## How to play
1. Words run in any of 8 directions.
2. Drag across the letters.
3. Find them all.

## Tips
- Scan for rare letters first.
