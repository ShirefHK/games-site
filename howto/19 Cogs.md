# Cogs

## Goal
Level-based cog puzzle. Get the cogs turning so the bell rings.

## Controls
| Input | Action |
| --- | --- |
| Mouse | Interact with the cogs on the board |
| Enter | Next level |
| N / P | Next / previous level |
| R | Restart level |

## How to play
1. Study the starting layout.
2. Rearrange the cogs so they all mesh and spin.
3. When the bell rings, press Enter for the next level.

## Tips
- The Moves counter is shown; try to use fewer moves.
