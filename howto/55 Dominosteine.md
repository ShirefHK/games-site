# Dominosteine

## Goal
Place dominoes so each of the 10 stones is used exactly once.

## Controls
| Input | Action |
| --- | --- |
| Click, click | Place a domino |
| Click domino | Remove |
| R | New puzzle |

## How to play
1. Click a cell then a neighbour.
2. Click a placed domino to remove it.
3. Each of the 10 stones used exactly once.

## Tips
- Start with rare numbers.
