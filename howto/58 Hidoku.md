# Hidoku

## Goal
Place numbers to make a path of consecutive neighbours (diagonals allowed).

## Controls
| Input | Action |
| --- | --- |
| Click | Select a cell |
| Digits | Enter number (two digits allowed) |
| Backspace | Clear |
| Arrows | Move |
| H | Hint |
| R | New puzzle |

## How to play
1. Click a cell and type its number.
2. Consecutive numbers are neighbours, including diagonals.
3. Fill the grid from lowest to highest.

## Tips
- Find where 1 and the largest number are.
