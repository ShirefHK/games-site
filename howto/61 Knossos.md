# Knossos

## Goal
Build walls on grid lines so each room has the right perimeter.

## Controls
| Input | Action |
| --- | --- |
| Click a grid line | Build / remove a wall |
| R | New puzzle |

## How to play
1. Each room needs exactly one number.
2. The number = its perimeter in wall segments.
3. Click lines to place walls.

## Tips
- Count the perimeter carefully.
