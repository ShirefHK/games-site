# Endview

## Goal
Place letters so that the ones you see from the edge match.

## Controls
| Input | Action |
| --- | --- |
| Click | Select cell |
| A / B / C | Write letter |
| X or 0 | Empty |
| Backspace | Clear |
| R | New puzzle |

## How to play
1. Click a cell and press A, B or C.
2. Edge clues show which letter is seen first from that side.
3. Each row and column holds each letter once, plus empties.

## Tips
- Click again to cycle through values.
