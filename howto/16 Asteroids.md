# Asteroids

## Goal
Pilot a ship, blast the rocks and avoid collisions.

## Controls
| Input | Action |
| --- | --- |
| ← → | Rotate |
| ↑ | Thrust |
| Space | Fire |
| R | Restart |

## How to play
1. Turn the ship with ← →, thrust with ↑.
2. Shoot rocks with Space; big rocks split into smaller ones.
3. One collision ends the run.

## Tips
- Use short bursts of thrust; it is hard to slow down.
