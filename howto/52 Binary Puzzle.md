# Binary Puzzle

## Goal
Fill the grid with 0 and 1.

## Controls
| Input | Action |
| --- | --- |
| Click | Cycle a cell |
| Right click | Cycle backward |
| R | New puzzle |

## How to play
1. No more than two of the same digit in a row.
2. Each row and column has equal 0s and 1s.
3. No two rows or columns are identical.

## Tips
- Fill in forced cells.
