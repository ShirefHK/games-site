# Chiiki

## Goal
Fill the grid with letters so each letter forms one connected region of the shown size.

## Controls
| Input | Action |
| --- | --- |
| Click | Select a cell |
| A–Z | Fill the cell |
| Backspace | Clear |
| R | New puzzle |

## How to play
1. Click a cell and press a letter.
2. Each letter is one connected region of the given size.
3. Fill every cell.

## Tips
- Click the legend letter as a shortcut.
