# Sudoku

## Goal
Classic Sudoku: fill the 9×9 grid with 1–9.

## Controls
| Input | Action |
| --- | --- |
| Click | Select a cell |
| 1–9 | Write a digit (0 clears) |
| N | Toggle pencil-notes mode |
| H | Hint |
| R | New puzzle |

## How to play
1. Click an empty cell to select it.
2. Type a digit. Every row, column and box must hold each digit exactly once.
3. Use pencil notes (N) to jot candidates when you are not sure.
4. Stuck? Press H for a hint. The board says SOLVED! when every cell is right.

## Tips
- Start with rows, columns or boxes that are almost full.
- Pencil mode keeps your guesses from locking in mistakes.
