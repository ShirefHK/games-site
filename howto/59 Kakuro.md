# Kakuro

## Goal
Cross-sum puzzle: fill white cells with 1–9 to match the clues.

## Controls
| Input | Action |
| --- | --- |
| Click | Select a white cell |
| 1–9 | Write a number (0 / Backspace clears) |
| Arrows | Move |
| R | New puzzle |

## How to play
1. Clues give the sum of a run.
2. Digits in a run cannot repeat.
3. Fill all white cells.

## Tips
- Learn the unique combos, like 3 = 1+2.
