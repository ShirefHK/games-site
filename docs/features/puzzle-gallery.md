# Puzzle gallery

The Puzzles section of the landing page shows the cube solver with pictures.

- **Feature card:** a large 3×3×3 cube image, a description and an **Open solver** button.
- **Gallery:** seven image tiles that link to `cube-solver/`: 2×2×2, 3×3×3, 4×4×4, 5×5×5, Skewb, Pyraminx and Megaminx.
- **Images:** generated SVGs in `thumbs/` (`cube-2x2.svg`, `cube-solver.svg`, `cube-4x4.svg`, `cube-5x5.svg`, `skewb.svg`, `pyraminx.svg`, `megaminx.svg`).
- **Not covered:** `cube-solver/index.html` itself has no pictures; the gallery is only on the landing page.
